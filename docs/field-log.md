# Field Log

`/radio/field-log/` is a derived static view of portable operating history. Its
durable source is `src/data/pota/parks.json`, which is generated by the existing
POTA update workflow. Public note metadata supplies report links and optional
series/trip labels; draft and unlisted notes are never associated.

Each activation is one timeline entry and one map marker. The initial filters
cover year, mode, and series. With JavaScript disabled, the complete
chronological list and all park/report links remain available. JavaScript adds
filtering, marker synchronization, Arrow Up/Down movement between visible
timeline buttons, and URL-backed filter state.

Do not edit field-log entries by hand. Refresh the underlying datasets with
`mise run pota:update`, then run the normal tests and production build.
